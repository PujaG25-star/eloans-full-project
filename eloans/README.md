# eLoans — Fintech Loan Marketplace

A production-style React + TypeScript + Vite fintech prototype based on the eLoans product requirements.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Included

- Responsive fintech dashboard and navigation
- Loan marketplace with 15 loan categories
- Loan and bank detail pages
- Bank offers and comparison
- Working EMI calculator with chart and amortization snapshot
- Multi-step eligibility flow
- Multi-step loan application flow
- Application tracking timeline
- Active loan portfolio
- EMI payment history
- Credit score dashboard
- Document management UI
- Personalized offers
- Insurance marketplace and details
- Support center
- Profile/security UI
- Global search
- Notifications dropdown
- AI Loan Assistant demo
- About, services and office location pages
- Reusable TypeScript components and mock data

## Prototype note

Financial, lender, credit, payment, insurance, map, and AI integrations are intentionally mocked. No real payment, lender submission, credit inquiry, insurance policy issuance, or sensitive-data transmission is performed.
